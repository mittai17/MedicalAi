# SwasthAI

## Offline Edge AI Powered Medical Diagnosis & Rural Healthcare Platform

SwasthAI is a production-ready Android application that provides AI-assisted medical diagnosis, disease prediction, risk assessment, and clinical decision support for rural communities.

### Features
- 🏥 AI Medical Diagnosis (on-device Edge AI)
- 🎤 Voice-based Symptom Analysis
- 📷 Image-based Disease Screening
- 📊 Risk Classification (Low/Moderate/High)
- 📱 Offline-first Architecture
- 🔄 Background Synchronization
- 👩‍⚕️ Health Worker Assistance
- 📋 Digital Medical Records

### Tech Stack
- **Android** + Kotlin + Jetpack Compose
- **Material Design 3** with dual themes (Citizen/Health Worker)
- **MVVM** + Clean Architecture + Repository Pattern
- **TensorFlow Lite** for Edge AI inference
- **Room** + SQLCipher for encrypted local storage
- **WorkManager** for background sync
- **Hilt** for dependency injection

### Getting Started
1. Open in Android Studio Ladybug or later
2. Sync Gradle
3. Build and run on device/emulator (API 26+)
